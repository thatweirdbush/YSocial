# Media - implementation plan

Spec: `docs/specs/2026-10-21-media-design.md` (rev 2, APPROVED 2026-10-21). Order: BE (domain -> infra -> app/API + tests) -> swagger -> FE -> real smoke. TDD per task; commit per task (author = user, no trailers).

## Tasks
- [ ] **A1 Contract:** codes `PayloadTooLarge` 413, `MediaStorageUnavailable` 503, `TooManyRequests` 429 (+ `ApiProblems`, snapshot, MAP §1.1), MAP D33/D34 draft rows
- [ ] **A2 Domain:** `MediaAsset` status machine + `Version`, rules, `Post.Media` (limit, empty-content rule), tests first (every transition)
- [ ] **A3 Infra:** EF configs (`Version` token, `User.MediaQuotaVersion`), migration `AddMedia`, `IMediaAssetRepository` (set-based), `Store` sets, model tests
- [ ] **A4 Storage:** `IMediaStorage`, strict `OwnsUrl` (+ table tests), `CloudinaryMediaStorage` (strip flag, kind check), `UnavailableMediaStorage`, DI choice, `FakeMediaStorage` with fault injection
- [ ] **A5 Upload:** write-ahead handler (reserve under quota token, upload, mark pending, compensation), validator (limit table, magic bytes, pixel header), gates (429), `MediaController` (`[FromForm]`, size limits), cancellation, `LogRedactor` guard
- [ ] **A6 Discard & sweep:** `DELETE media/{id}` (claim), `MediaCleanupProcessor` (claim races, retry, missing = success) + hosted job, `ApiFactory` removes it
- [ ] **A7 Posts & avatar:** `mediaIds` atomic attach, `PostDto.media`, media-only posts, avatar precedence & transaction (D34), spoof guards, integration tests, swagger pins
- [ ] **A8 Health:** `AddHealthChecks` media-storage check (`Degraded`), `/health`, startup warning, tests
- [ ] **A9 Contract docs & swagger:** MAP §2/§3/§7, BG deployment notes (proxy, temp disk), export swagger, `api:generate`, `api:check`
- [ ] **A10 FE foundation:** strict `media-loader`, `MediaImage`, `UserAvatar`, `ui-store` mute, `VideoPlayer` + coordinator, capability `mediaUpload`
- [ ] **A11 FE media UI:** grid & lightbox rewrite, avatar call-site migration, mapper/types
- [ ] **A12 FE upload:** compression with fallbacks, `useMediaUploadQueue`, composer adapter, reply guard, real `createPost`, edit-profile avatar payloads
- [ ] **A13 Verify:** full BE + FE suites, typecheck, lint, real smoke with Cloudinary (upload, post, avatar, discard, sweep, deletion proof, EXIF/GPS bytes check)
- [ ] **A14 As-built:** `.context` docs (BG, DM, MAP, `features/media.md`, post-creator, profile, roadmap, INDEX), deferred triage, final review
