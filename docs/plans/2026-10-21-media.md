# Media - implementation plan

Spec: `docs/specs/2026-10-21-media-design.md` (rev 2, APPROVED 2026-10-21). Order: BE (domain -> infra -> app/API + tests) -> swagger -> FE -> real smoke. TDD per task; commit per task (author = user, no trailers).

## Tasks
- [x] **A1 Contract:** codes `PayloadTooLarge` 413, `MediaStorageUnavailable` 503, `TooManyRequests` 429 (+ `ApiProblems`, snapshot, MAP §1.1), MAP D33/D34 draft rows
- [x] **A2 Domain:** `MediaAsset` status machine + `Version`, rules, `Post.Media` (limit, empty-content rule), tests first (every transition)
- [x] **A3 Infra:** EF configs (`Version` token, `User.MediaQuotaVersion`), migration `AddMedia`, `IMediaAssetRepository` (set-based), `Store` sets, model tests
- [x] **A4 Storage:** `IMediaStorage`, strict `OwnsUrl` (+ table tests), `CloudinaryMediaStorage` (strip flag, kind check), `UnavailableMediaStorage`, DI choice, `FakeMediaStorage` with fault injection
- [x] **A5 Upload:** write-ahead handler (reserve under quota token, upload, mark pending, compensation), validator (limit table, magic bytes, pixel header), gates (429), `MediaController` (`[FromForm]`, size limits), cancellation, `LogRedactor` guard
- [x] **A6 Discard & sweep:** `DELETE media/{id}` (claim), `MediaCleanupProcessor` (claim races, retry, missing = success) + hosted job, `ApiFactory` removes it
- [x] **A7 Posts & avatar:** `mediaIds` atomic attach, `PostDto.media`, media-only posts, avatar precedence & transaction (D34), spoof guards, integration tests, swagger pins
- [x] **A8 Health:** `AddHealthChecks` media-storage check (`Degraded`), `/health`, startup warning, tests
- [x] **A9 Contract docs & swagger:** MAP §2/§3/§7, BG deployment notes (proxy, temp disk), export swagger, `api:generate`, `api:check`
- [x] **A10 FE foundation:** strict `media-loader`, `MediaImage`, `UserAvatar`, `ui-store` mute, `VideoPlayer` + coordinator, capability `mediaUpload`
- [x] **A11 FE media UI:** grid & lightbox rewrite, avatar call-site migration, mapper/types
- [x] **A12 FE upload:** compression with fallbacks, `useMediaUploadQueue`, composer adapter, reply guard, real `createPost`, edit-profile avatar payloads
- [x] **A13 Verify:** full BE + FE suites, typecheck, lint, real smoke with Cloudinary (upload, post, avatar, discard, sweep, deletion proof, EXIF/GPS bytes check)
- [x] **A14 As-built:** `.context` docs (BG, DM, MAP, `features/media.md`, post-creator, profile, roadmap, INDEX), deferred triage, final review

## Mismatch log
- **PostMedia snapshot:** spec list omitted `Bytes`, but `MediaDto.bytes` is shared by upload & post: snapshot keeps it (AddMedia migration regenerated before any apply) - decided BE
- **Upload 503:** spec flow reserved rows before the provider check; with missing keys that left `Deleting` rows: the handler now answers 503 BEFORE reserving (and discard likewise) - decided BE
- **413 on TestServer:** `[RequestSizeLimit]` is ignored there; a resource filter on declared `Content-Length` was added (Kestrel still cuts chunked bodies) - decided BE
- **Form field names:** Swashbuckle published `Files`/`Purpose`; `[FromForm(Name)]` pins `files`/`purpose` - decided BE
- **Mock avatars/stock images:** composer mention suggestions & main layout had unsplash avatars: removed (initials) - decided FE
- **Aspect boxes:** frontend.md forbids inline CSS, so the ratio is snapped to static Tailwind buckets instead of an exact `aspect-ratio` - decided FE
- **Not verified:** PostgreSQL media tests (no server), visual browser check of the new UI, chunked video upload > 20 MiB, real Kestrel 413
